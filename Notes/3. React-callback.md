React Callback — Simple Explanation

In React, a callback is a function that is passed as an argument to another function/component and executed later.

1. Simple JavaScript callback
function greet(name, callback) {
  console.log("Hello " + name);
  callback();
}

function done() {
  console.log("Completed");
}

greet("Saravanan", done);

Output:

Hello Saravanan
Completed

Here:

done

is the callback function.

2. Callback in React

A common example is parent → child communication.

function Parent() {
  const handleMessage = (message) => {
    console.log(message);
  };

  return <Child onSend={handleMessage} />;
}

function Child({ onSend }) {
  return (
    <button onClick={() => onSend("Hello Parent")}>
      Send
    </button>
  );
}

Flow:

Parent
  │
  │ passes callback
  ↓
Child
  │
  │ calls callback
  ↓
Parent function executes

So:

<Child onSend={handleMessage} />

passes the callback.

And:

onSend("Hello Parent")

executes it.

3. Callback vs callback function
<button onClick={handleClick}>

React receives the function reference.

But:

<button onClick={handleClick()}>

calls the function immediately during rendering, which is usually wrong for an event handler.

For passing parameters:

<button onClick={() => handleClick(10)}>
  Click
</button>

Here the arrow function acts as a callback.

Interview definition

A callback in React is a function passed to another component or function and invoked later, commonly used for event handling and communication from child components to parent components.
