
## React Hooks

- React Hooks are `special functions` 
- that let you use state, `lifecycle features`,
- and other React features inside `functional components`.


### Most important hooks


| Hook                  | Purpose                            |
| --------------------- | ---------------------------------- |
| `useState`            | Manage component state             |
| `useEffect`           | Perform side effects / API calls   |
| `useContext`          | Access Context data                |
| `useRef`              | Store a value / access DOM element |
| `useMemo`             | Optimize expensive calculations    |
| `useCallback`         | Memoize a function                 |
| `useReducer`          | Manage complex state               |
| `useLayoutEffect`     | Run effect before browser paints   |
