## JSX (JavaScript XML)

 Writing **HTML inside JavaScript** It is mainly used in React

###  Simple Example 

 Looks like HTML but actually written inside JavaScript ✅
```
function Sample(){

  return (
    <div>
      <h1> Welcome to React Js </h1>
    </div>
  )
}
```



### 🧠 Why JSX?

Without JSX:
```
React.createElement("h1", null, "Hello");
```
With JSX:

```
<h1>Hello</h1>
```
👉 JSX is easier to read and write

## 📌 Basic Rules
### 1. One parent element

```
<div>
  <h1>Hello</h1>
  <p>Hi</p>
</div>
```
###  2. Close all tags
```
<img src = {"./img.png"} />
```
###  3. Use className
```
<div className={"box"}></div>
```
### 4. Use JavaScript inside JSX `{}`
```
import {useState} from "react"


function Sample(){

  const [name,setName] = useState("Savanan")

  return (
    <div>
      <h1> Hello {name} !! </h1>
    </div>
  )
}
```
### 5 Important

Only expressions allowed:
```
<h1>{5 + 5}</h1>   ✅
```
