## React Bootstrap

- React Bootstrap is a library that lets you use Bootstrap components directly 
- in React—without writing much custom CSS.

- Instead of using raw HTML classes like class="btn btn-primary", you use ready-made React components.

#### 🚀 Install
```
npm install react-bootstrap bootstrap
```
Then import Bootstrap CSS (important!):
```
import 'bootstrap/dist/css/bootstrap.min.css';
```
#### 🧱 Basic Example
```
import Button from 'react-bootstrap/Button';

function App() {
  return <Button variant="primary">Click Me</Button>;
}
```
📦 Common Components
### Button
```
<Button variant="success">Success</Button>
<Button variant="danger">Danger</Button>
```
### Navbar
```
import Navbar from 'react-bootstrap/Navbar';
import Container from 'react-bootstrap/Container';

function App() {
  return (
    <Navbar bg="dark" variant="dark">
      <Container>
        <Navbar.Brand>My App</Navbar.Brand>
      </Container>
    </Navbar>
  );
}
```
### Card
```
import Card from 'react-bootstrap/Card';

function App() {
  return (
    <Card style={{ width: '18rem' }}>
      <Card.Body>
        <Card.Title>Card Title</Card.Title>
        <Card.Text>Some text here</Card.Text>
      </Card.Body>
    </Card>
  );
}
```
### ✅ Why use React Bootstrap?
- No need to manually write Bootstrap classes
- Clean React component syntax
- Fully responsive UI
- Saves development time
