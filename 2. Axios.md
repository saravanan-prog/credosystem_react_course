## React + Axios (Simple & Practical Guide)

 Axios is a **popular library used in React to make API requests**
```

 - GET       -  axios.get(pathUrl)
 - POST      -  axios.post(pathUrl,payload)
 - PUT       -  axios.put(pathUrl?queryParam,payload)
 - DELETE    -  axios.delete(pathUrl?queryParam,payload)

```     
It is easier than fetch() and provides better 
 - error handling, 
 - interceptors, and 
 - cleaner syntax

#### 1️⃣ Install Axios

```
npm install axios
```

####  Create Axios service file

***axios.service.js***

```
import axios from 'axios'

const apiEndpoint = axios.create(
  {
    baseURL : "https://fakestoreapi.com/"
    timeout:5000
  }
)

export const axiosGetApicall = async apiEndpoint.get(pathurl,signal) => {
   const response =  await apiEndpoint.get(pathurl,{signal})
   return response?.data
}

export const axiosPostApicall = async apiEndpoint.post(pathurl,payload,signal) => {
  const response =  await apiEndpoint.post(pathurl,payload,{signal})
  return response?.data
}

export const axiosPutApicall = async apiEndpoint.put(pathurl,payload,signal) => {
  const response =  await apiEndpoint.put(pathurl,payload,{signal})
}

export const axiosDeleteApicall = async apiEndpoint.delete(pathurl,signal) => {
   const response =  await apiEndpoint.delete(pathurl,payload,{signal})
   return response?.data
}

```


#### 2️⃣ Basic GET Request in React

```

import { useEffect, useState } from "react";
import {axiosGetApicall} from './service/axios-service'
const controller = new AbortController()

function Users() {
  const [users, setUsers] = useState([]);

  useEffect(() => {
    fetchUsers();
  }, []);

  async function fetchUsers() {
      try {
        const response = await axiosGetApicall('/users',controller.signal)
        setUsers(response);
      } catch (error) {
        console.error(error.message);
      }
    }

  return (
    <ul>
      {users.map(user => (
        <li key={user.id}>{user.name}</li>
      ))}
    </ul>
  );
}


```

#### 6️⃣ Why Axios is better than fetch?

| Feature         | fetch  | Axios     |
| --------------- | ------ | --------- |
| JSON parsing    | manual | automatic |
| Error handling  | tricky | easy      |
| Interceptors    | ❌     | ✅        |
| Timeout support | ❌     | ✅        |
| Cleaner syntax  | ❌     | ✅        |
