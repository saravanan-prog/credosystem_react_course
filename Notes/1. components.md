## What is a Component?

In React:

-  A component is a **small piece of UI** (User Interface)
-  You build a big app using many **small components**

#### For examples:

> Button,
> Header,
> Card,
> Navbar


## Structure

 Simple Idea:
> `Component` is a function that `returns UI`


```
function DemoPage() {
  
  return(
    <>
      <h1>Hello World</h1>;
    </>
  )
}


```
> Use it like: `<DemoPage />`

## 🔁 Reusable Components

 Write once, use many times
```
function Header() {
  return (
    <div>
      <nav>
         <ul>
           <li> Home </li>
           <li> About </li>
           <li> Contact </li>
           <li> Blogs </li>
         </ul>
      </nav>
    </div>
  );
}

```
> `<Header />`

> `<Header />`

> `<Header />`

## 🔀 Types of Components
### 1. Functional Component (modern)

- Function name starts with capital letter
- Returns JSX
- Can be reused

```
function App() {
  return (
    <>
      <h1>Hello</h1>
    </>
  )
}
```
### 2. Class Component (old)

- class name starts with capital letter
- render method returns to JSX
- Can be reused


```
import { Component } from 'react'
class App extends Component {
  render() {
    return (
      <>
        <h1>Hello</h1>;
      </>
    )
  }
}
```
