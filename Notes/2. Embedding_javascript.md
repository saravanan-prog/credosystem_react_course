# 🟡 Embedding JavaScript in JSX

👉 In React, you can write JavaScript inside JSX using:
```
👉 { } (curly braces)
```
### 🧾 Basic Example
```
const name = "Arun";

<h1>Hello {name}</h1>

👉 Output: Hello Arun
```
🧠 What can you write inside {}?

### ✅ 1. Variables
```
const age = 20;
<p>Age: {age}</p>
```
### ✅ 2. Calculations
```
<p>{10 + 5}</p>

👉 Output: 15
```

### ✅ 4. Expressions (very important)
```
const isLoggedIn = true;
<h1>{isLoggedIn ? "Welcome" : "Please Login"}</h1>

```

🎯 Simple Rule

- 👉 { } = “JavaScript goes here”
- 👉 Only things that return a value (expressions)

🧾 Real-Life Example
```
const user = "Ravi";

<div>
  <h1>Hello {user}</h1>
  <p>{user.length} letters</p>
</div>
```
### 🧾 One-Line Summary
```
👉 Use {} to write JavaScript inside JSX
```
