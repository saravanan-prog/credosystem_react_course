## Passing Functions as Props

Very important for real apps 👇


### Parent Copmponent

Parent.jsx
```
function Parent() {

  const handleClick = () => {
    alert("Clicked!");
  };

  return <>
      <Child handleClick = {handleClick} />;
  </>
};
```
### Child Copmponent

Child.jsx
```
function Child ({ handleClick }) {

  return <>
      <button onClick={handleClick}>Click Me</button>;
  </>

};
```
