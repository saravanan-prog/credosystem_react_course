🟡 JSX vs HTML

👉 JSX is used in React
👉 It looks like HTML, but it is not exactly the same

📊 Main Differences

## 1. class vs className

#### 🟥 HTML:
```
<div class="box"></div>
```
#### 🟩 JSX:
```
<div className="box"></div>
```
👉 Because class is a reserved word in JavaScript

## 2. for vs htmlFor

#### 🟥 HTML:
```
<label for="name">Name</label>
```
#### 🟩 JSX:
```
<label htmlFor="name">Name</label>
```
## 3. All tags must be closed

#### 🟥 HTML:
```
<img src="img.png">
```
#### 🟩 JSX:
```
<img src="img.png" />
```
## 4. JavaScript inside JSX

#### 🟥 HTML:
```
<h1>5 + 5</h1>
```
#### 🟩 JSX:
```       
<h1>{5 + 5}</h1>
```
👉 {} allows JavaScript

## 5. Attribute names are camelCase

#### 🟥 HTML:
```
<button onclick="clickMe()"></button>
```
#### 🟩 JSX:
```
<button onClick={clickMe}></button>
```
## 6. One parent element required

#### 🟩 JSX:
```
<div>
  <h1>Hello</h1>
  <p>Hi</p>
</div>
```
