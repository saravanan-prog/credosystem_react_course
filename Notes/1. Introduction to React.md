## 🟢 1. What is React?

- React is a open-source  `JavaScript library` for building user interfaces (UI).
- Developed by `Meta` formely known as `facebook`.
- Used for building `single-page applications` (SPA)
- Focuses on `components`


## 🟡 2. Why Use React?
- Problems with Traditional JavaScript:
- Manual DOM updates
- Hard to maintain large apps
- Code becomes messy

 React Solves:
```
    - Efficient updates
    - Reusable components
    - Clean structure
```
