# 🟡 JSX (JavaScript XML)

### 👉 JSX means:
- writing HTML inside JavaScript
- It is mainly used in React

### 🧾 Simple Example
```
const element = <h1>Hello</h1>;
```

- Looks like HTML
- But actually written inside JavaScript ✅

### 🧠 Why JSX?

Without JSX:
```
React.createElement("h1", null, "Hello");
```
With JSX:

```
<h1>Hello</h1>
```
👉 JSX is easier to read and write

## 📌 Basic Rules
#### ✅ 1. One parent element

```
<div>
  <h1>Hello</h1>
  <p>Hi</p>
</div>
```
#### ✅ 2. Close all tags
```
<img src="img.png" />
```
#### ✅ 3. Use className
```
<div className="box"></div>
```
#### 🔁 Use JavaScript inside JSX

👉 Use { }
```
const name = "Ravi";

<h1>Hello {name}</h1>
```
#### ❗ Important

👉 Only expressions allowed:
```
<h1>{5 + 5}</h1>   ✅
```
