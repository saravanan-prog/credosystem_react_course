
## Redux-toolkit

- Redux Toolkit (RTK) is the `official, recommended` way to use Redux in modern apps
- It `simplifies` setup,
- `reduces boilerplate`, and makes 
- state management easier and less `error-prone—especially` in apps built with React.


### 🧱 Core Concepts in Redux Toolkit

#### 1. configureStore

Creates the `Redux store` with good defaults.

```
import { configureStore } from '@reduxjs/toolkit'
import counterReducer from './counterSlice'

export const store = configureStore({
  reducer: {
    counter: counterReducer                /* Counter  state  stored*/
  }
})

```

#### 2. createSlice

Defines `state + reducers` in one place.

```
import { createSlice } from '@reduxjs/toolkit'

const counterSlice = createSlice({
  name: 'counter',
  initialState: { value: 0 },
  reducers: {
    increment: (state) => {
      state.value += 1
    },
    decrement: (state) => {
      state.value -= 1
    }
  }
})

export const { increment, decrement } = counterSlice.actions
export default counterSlice.reducer
```

#### 3. Async Logic with createAsyncThunk

```
import { createAsyncThunk } from '@reduxjs/toolkit'

export const fetchData = createAsyncThunk(
  'data/fetch',
  async () => {
    const response = await fetch('https://api.example.com/data')
    return response.json()
  }
)
```
#### 4. Using in React   

```
import { useSelector, useDispatch } from 'react-redux'
import { increment } from './counterSlice'

function Counter() {
  const count = useSelector(state => state.counter.value)
  const dispatch = useDispatch()

  return (
    <div>
      <p>{count}</p>
      <button onClick={() => dispatch(increment())}>
        Increment
      </button>
    </div>
  )
}
```
