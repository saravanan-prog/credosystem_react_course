## What are Props?

Props (short for `properties` ) are used to pass data from a `parent component to a child component`.
- They are read-only (immutable)
- They help make components reusable


```
               PARENT COMPONENT
          ┌─────────────────────┐
          │                     │
          │   name = "Saravanan"│
          │   age = 34          │
          │                     │
          └──────────┬──────────┘
                     │
                     │  PROPS
                     │
                     ↓
          ┌─────────────────────┐
          │   CHILD COMPONENT   │
          │                     │
          │   name              │
          │   age               │
          │                     │
          └─────────────────────┘
```


## Basic Example
Parent Component
```
function App ()  {

  return <div>

      <User 
        name = {"Saravanan"} 
        age = {34} 
      />
  </div>;
};
```
Child Component
```
function User (props){
  
  return <div>
    <p> Customer Name : {props.name}  </p>
    <p> Customer Age : {props.age} </p>
  </div>
}
```
✔️ Parent (App) → passes data


#### 🔹 Props with Destructuring (Best Practice)

```
function User ({ 
    name, 
    role 
  })  {
  return <div>
    <p> Customer Name : {name}  </p>
    <p> Customer Age  : {age} </p>
  </div>
};

👉 Cleaner and widely used in real projects
```

#### 🔹 Props are Read-Only
```
 ❌ Wrong:

props.name = "New Name"; // Not allowed

```


## 🔹 Passing Different Types of Props

#### String
```
<User name="Saravanan" />
```
#### Number
```
<User age={28} />
```
#### Boolean
```
<User isAdmin={true} />
```
#### Object
```
<User user={{ name: "Saravanan", role: "Developer" }} />
```
