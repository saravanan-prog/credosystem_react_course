# 🧠 Virtual DOM vs Real DOM

### 🟥 Real DOM (Actual Web Page)
```
👉 Real DOM = what you see in the browser
```
- It is the real HTML structure
- When something changes → whole page (or large part) updates
This is slow
- 📌 Example:
```
If you change one button text:
👉 Browser may re-check and update many elements
```
### 🟩 Virtual DOM (Copy of Real DOM)

- 👉 Virtual DOM = lightweight copy of the real DOM
- Used by React
```
    - Stored in memory (not visible)
    - Faster to update
    - Only updates what changed
```


### ⚙️ How Virtual DOM Works (Simple Steps)
- Page loads    → Virtual DOM is created
- You change something (like text)
- React creates a new Virtual DOM
- Compares with old Virtual DOM (called “diffing”)
- Updates only the changed part in Real DOM

👉 This makes it fast ⚡
