## React Router

- React Router is what you use in React apps to handle navigation without reloading the page—basically turning -  your app into a single-page application (SPA).
- Let’s go step by step so it feels practical, not abstract.

#### 🚀 1. Installation
```
npm install react-router-dom
```
#### 🧭 2. Basic Setup (Routing Basics)
You wrap your app with a router and define routes.
```
import { BrowserRouter, Routes, Route } from "react-router-dom";
function App() {  
    return (    
        <BrowserRouter>      
            <Routes>        
                <Route path="/" element={<h1>Home</h1>} />        
                <Route path="/about" element={<h1>About</h1>} />    
            </Routes>    
        </BrowserRouter>  
    );}

```
🧠 What’s happening:

```
BrowserRouter   → enables routing
Routes          → container for all routes
Route           → defines each page

```

🔗 3. Navigation: Link & NavLink
Instead of <a> tag (which reloads page), use Link.

Link
```
import { Link } from "react-router-dom";
<Link to="/">Home</Link><Link to="/about">About</Link>
```
NavLink (active styling)
```
import { NavLink } from "react-router-dom";
<NavLink to="/" style={({ isActive }) => ({  color: isActive ? "red" : "black"})}>  Home</NavLink>
```
👉 NavLink helps you highlight the active page.

🔄 4. Dynamic Routing
Used when you don’t know the exact path in advance (like user profile pages).

Step 1: Create dynamic route
```
<Route path="/user/:id" element={<User />} />
```
Step 2: Access the parameter
```
import { useParams } from "react-router-dom";function User() {  const { id } = useParams();  return <h1>User ID: {id}</h1>;}
```

Step 3: Navigate dynamically
```
<Link to="/user/101">User 101</Link><Link to="/user/202">User 202</Link>
```
🧠 Simple mental model
```

/           → Home page
/about      → About page
/user/101   → Dynamic page (id = 101)

```

⚡ Real-world example structure
```
    /    → Home/about   
           → About/contact   
            → Contact/user/:id   → User Profile
```

⚠️ Common beginner mistakes


- ❌ Using <a href=""> instead of Link
- ❌ Forgetting BrowserRouter
- ❌ Wrong path (case-sensitive sometimes)
- ❌ Not installing react-router-dom
