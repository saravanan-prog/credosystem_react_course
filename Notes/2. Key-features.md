##  Key Features of React

  ####  1. Component-Based Architecture
  - UI is broken into small reusable parts
    Example
  ```
    Navbar
    Profile Card
    Footer
  ```
  #### 2.  Virtual DOM
  - A lightweight copy of the real DOM
  - Stored in memory (not in browser)

  


  ```
        Faster updates
        Better performance
  ```
  #### 3. Declarative UI
  -  you simply describe what the UI should look like for a given state.
##### ❌ Imperative (manual steps)
  ```

  const button = document.querySelector("button");

  button.addEventListener("click", () => {
    document.body.innerHTML = "<h1>Hello World</h1>";
  });


  Here, you:
    Find elements
    Attach listeners
    Manually change DOM


  ```
##### ✅ Declarative (React way)
 ```
  function App() {
    const [clicked, setClicked] = React.useState(false);

    return (
      <div>
        {clicked ? <h1>Hello World</h1> : <button onClick={() => setClicked(true)}>Click me</button>}
      </div>
    );
  }

  In React:
    You change the state
    React updates the UI

 ```
