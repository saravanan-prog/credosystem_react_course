
 # QUERY-PARAM-ROUTING

Query params are extra information added to a URL after the **?** symbol. They are often used to pass values like a search keyword, product category, or page number.
 
 URL:

> http://localhost:5173/products?category=mobile

- `?` starts the query parameters.

- category is the parameter name.

- mobile is the parameter value

```
import { useLocation } from "react-router-dom";

function Products() {
  const location = useLocation();

  const queryParams = new URLSearchParams(location.search);
  const category = queryParams.get("category");

  return (
    <div>
      <h2>Products Page</h2>
      <p>Category: {category}</p>
    </div>
  );
}

export default Products;

```

- **useLocation()** gets the current URL information.

- **location.search** gets ?category=mobile.

- **URLSearchParams()** helps read the query parameters.

- **.get("category")** gets the value mobile
