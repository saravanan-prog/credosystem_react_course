
### React memoization

- In React, memoization is used to avoid unnecessary re-renders and expensive recalculations.

- React provides several memoization tools:

1. React.memo()

Used for component memoization.

It prevents a component from re-rendering if its props haven’t changed.

```
import React from "react";

Child.jsx
=========

const Child = React.memo(({ name }) => {
  console.log("Child rendered");
  return <h1>{name}</h1>;
});

App.jsx
=======
export default function App() {
  const [count, setCount] = React.useState(0);

  return (
    <div>
      <Child name="Saravanan" />

      <button onClick={() => setCount(count + 1)}>
        Count: {count}
      </button>
    </div>
  );
}

```
#### What happens?
- Clicking the button re-renders App
- But Child does NOT re-render
- Because name prop didn’t change


### 2. useMemo()

- Used to memoize computed values.
- Useful for expensive calculations.

##### Example
```
const expensiveValue = useMemo(() => {
  return heavyCalculation(data);
}, [data]);
```
##### Meaning
- React stores the result
- Recalculates only when data changes



#### 3. useCallback()

- Used to memoize functions.
- Important when passing callbacks to child components.

#### Example
```
const handleClick = useCallback(() => {
  console.log("clicked");
}, []);
```
Without useCallback, a new function is created every render.
