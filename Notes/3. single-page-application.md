# 🌐 What is SPA (Single Page Application)?

A Single Page Application (SPA) means:

- 👉 The website loads `only one page` once
- 👉 After that, it changes `content without reloading`

### 🧠 Simple Example
#### 🟥 Normal Website:
- You click “About”
- Page reloads ⏳
- New page opens
#### 🟩 SPA:
- You click “About”
- Content changes instantly ⚡
- No page reload
📱 Real-Life Example

Apps like:
```
Gmail
Facebook
```
- 👉 When you click different sections
- 👉 The page does NOT reload
- 👉 Only content changes
