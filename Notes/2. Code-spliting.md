### Code Splitting

- In React, Code Splitting is a performance optimization technique
- where your app’s JavaScript bundle is split into smaller chunks that are loaded only when needed.
- Instead of loading the entire app at once, 
- React loads parts of the app lazily.



#### 1. React.lazy()

Used to dynamically import components.

#### Example
```
import React, { Suspense } from "react";

const Dashboard = React.lazy(() => import("./Dashboard"));

function App() {
  return (
    <Suspense fallback={<h1>Loading...</h1>}>
      <Dashboard />
    </Suspense>
  );
}
```
#### What happens?
- Dashboard code is loaded only when needed
- fallback UI shows while loading


### 2. Route-based Code Splitting

- Very common with routers.
- Example using React Router:

```
const Home = lazy(() => import("./Home"));
const About = lazy(() => import("./About"));
```

- Each page gets its own bundle.
-  visiting /about loads only the About page bundle


### Full Example

```
import React, { Suspense, lazy } from "react";
import { Routes, Route, Link } from "react-router-dom";

// Lazy loaded components
const Home = lazy(() => import("./Home"));
const About = lazy(() => import("./About"));
const Contact = lazy(() => import("./Contact"));

function App() {
  return (
    

      <Suspense fallback={<h1>Loading Page...</h1>}>
        <Routes>
          <Route path="/" element={<Home />} />
          <Route path="/about" element={<About />} />
          <Route path="/contact" element={<Contact />} />
        </Routes>
      </Suspense>
    </div>
  );
}

export default App;
```
