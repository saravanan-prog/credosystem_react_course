## What are Props?

Props (short for “properties”) are used to pass data from a parent component to a child component.
- They are read-only (immutable)
- They help make components reusable


#### 🔹 Basic Example

```
const App = () => {
  return <User name="Saravanan" role="Developer" />;
};

const User = (props) => {
  return <h3>{props.name} - {props.role}</h3>;
};

✔️ Parent (App) → passes data
```

#### 🔹 Props with Destructuring (Best Practice)

```
const User = ({ name, role }) => {
  return <h3>{name} - {role}</h3>;
};

👉 Cleaner and widely used in real projects
```

#### 🔹 Props are Read-Only
```
 ❌ Wrong:

props.name = "New Name"; // Not allowed

```


## 🔹 Passing Different Types of Props

#### String
```
<User name="Saravanan" />
```
#### Number
```
<User age={28} />
```
#### Boolean
```
<User isAdmin={true} />
```
#### Object
```
<User user={{ name: "Saravanan", role: "Developer" }} />
```

## 🔹 Passing Functions as Props
```
Very important for real apps 👇

Parent.jsx
===========

const Parent = () => {

  const handleClick = () => {
    alert("Clicked!");
  };

  return <Child handleClick = {handleClick} />;
};

Child.jsx
===========

const Child = ({ handleClick }) => {

  return <button onClick={handleClick}>Click Me</button>;

};
```
