# ⚙️ Setting Up React
### 🟢 1. Install Node.js & npm

👉 First, install Node.js
(It automatically installs npm)

#### Steps:
- Go to: `https://nodejs.org`
- Download LTS version
- Install 

#### ✅ Check installation:

Open terminal / command prompt and type:
```
node -v
npm -v

👉 If versions show → ✅ Installed correctly
```
<img src="../Notes/asserts/node-version.png" height=300 width=700 />

### 🟡 2. Create React App (Easy Way)


Option  (Older Method) → Use Create React App
```
npx create-react-app my-react-project
```

<img src="../Notes/asserts/ins-end.png" height=300 width=500 />
