## Virutal Dom
 The **Virtual DOM is a lightweight copy of the actual DOM** stored in memory. It is used in React to update webpages efficiently.



```
       ┌───────────────────┐
       │   User Action     │
       │  (Data Changes)   │
       └─────────┬─────────┘
                 │
                 ▼
       ┌───────────────────┐
       │   New Virtual DOM │
       └─────────┬─────────┘
                 │
                 ▼
       ┌───────────────────┐
       │ Compare Old & New │
       │   Virtual DOM     │
       └─────────┬─────────┘
                 │
                 ▼
       ┌───────────────────┐
       │  Find Differences │
       └─────────┬─────────┘
                 │
                 ▼
       ┌───────────────────┐
       │  Update Real DOM  │
       │ (Changed Elements)│
       └─────────┬─────────┘
                 │
                 ▼
       ┌───────────────────┐
       │  Updated Webpage  │
       └───────────────────┘


```

## How it works:

Creates a virtual copy of the webpage.

When data changes, creates an updated Virtual DOM.

Compares the old and new Virtual DOM.

Updates only the changed parts of the real DOM.
