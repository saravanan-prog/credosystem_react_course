## Props Drilling 

Props Drilling means passing data from `a parent component to a deeply nested child component` through intermediate components, even when those intermediate components don't need the data.



```

App
 │
 │ username
 ↓
Parent
 │
 │ username
 ↓
Child
 │
 │ username
 ↓
GrandChild


```
Example

```
function App() {
    const username = "Saravanan";

    return <Parent username={username} />;
}

function Parent(props) {
    return <Child username={props.username} />;
}

function Child(props) {
    return <GrandChild username={props.username} />;
}

function GrandChild(props) {
    return <h1>Hello {props.username}</h1>;
}
```
