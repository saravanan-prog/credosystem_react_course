## React Router

- React Router is what you use in React apps to handle navigation without reloading the page—basically turning -  your app into a single-page application (SPA).
- Let’s go step by step so it feels practical, not abstract.

#### 🚀 1. Installation
```
npm install react-router-dom
```
#### 🧭 2. Basic Setup (Routing Basics)
You wrap your app with a router and define routes.
```
import { BrowserRouter, Routes, Route } from "react-router-dom";
function App() {  
    return (    
        <BrowserRouter>      
            <Routes>
                <Route Index element={<h1>Home</h1>} />                   
                <Route path={"/about"} element={<h1>About</h1>} /> 
                <Route path={"*"} element={<h1>Page Not Found</h1>} />   
            </Routes>    
        </BrowserRouter>  
    );}

```
🧠 What’s happening:

```
BrowserRouter   → enables routing
Routes          → container for all routes
Route           → defines each page

```

###  3. Navigation :-

`<Link />` is a React Router component used to move from one page to another when the user clicks a link.

It helps users navigate between pages without refreshing the entire browser page.

##### `Link`

```
import { Link } from "react-router-dom";

<Link to="/">Home</Link>
<Link to="/about">About</Link>
```

### React Router: useNavigate()

**useNavigate()** is a React Router hook used to move from one page to another using code.

```
import { useNavigate } from "react-router-dom";

function Login() {
  const navigate = useNavigate();

  return (
    <div>
      <h2>Login Page</h2>

      <button onClick={() => navigate("/home")}>
        Login
      </button>
    </div>
  );
}

export default Login;
```
