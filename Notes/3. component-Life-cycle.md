## What is Lifecycle?

A React class component goes through 3 major stages:

Figure 1
```

          CLASS COMPONENT
              │
      ┌───────┴────────┐
      ↓                ↓
   MOUNT             UPDATE
      │                │
      │                │
      └───────┬────────┘
              ↓
           UNMOUNT

```
Figure 2

## 1. Mounting Phase
```
              COMPONENT CREATED  MounitingPhase
                     │
                     ↓
              constructor()       // inital state value declare
                     │
                     ↓
                  render()       //Render the template
                     │
                     ↓
              componentDidMount()   // After Render the template
                     
              
```
## 2. Updating phase
```

              ┌─────────────┐
              │   UPDATE    │
              └─────────────┘
                     │
                setState()
                     │
                     ↓
                  render()
                     │
                     ↓
             componentDidUpdate(prevProps,prevState)
```
## 3. Unmounting phase

                     
                     
              ┌─────────────┐
              │   UNMOUNT   │      
              └─────────────┘
                     │
                     ↓
          componentWillUnmount()            ----> When the componet hide or remove the dom

```

| Method                   | Meaning             |
| ------------------------ | ------------------- |
| `constructor()`          | Initialize          |
| `render()`               | Display UI          |
| `componentDidMount()`    | After first display |
| `componentDidUpdate()`   | After update        |
| `componentWillUnmount()` | Before removal      |
