## Function Props

`Function as props` in React, it means `passing a function from the parent component to the child component` through props.
##### Flow:
```
Parent
  │
  │ function: showMessage
  ↓
Child
  │
  │ props.onClick()
  ↓
Parent function executes

```
##### Parent Component 
```

function Parent() {

    const showMessage = () => {
        alert("Hello from Parent");
    };

    return (
      <>
        <Child showMessage = {showMessage} />;
      </>
    )
}

```
##### Child Component 

```

function Child( { showMessage } ) {

    return (
        <button onClick={ showMessage }>
            Click Me
        </button>
    );
}

```




## React Callback — Simple Explanation

- In React, a `callback is a function` that is passed as an argument to another `function/component` and executed later.

- commonly used for `event handling` and communication from `child components to parent components`.


##### Flow:
```
Parent
  │
  │ passes callback
  ↓
Child
  │
  │ calls callback
  ↓
Parent function executes return data
 
```
