# Global State Management in React

- Instead of passing data through many components using props (prop drilling),
- we store it in a central/global place.

```
Managing data that needs to be accessed by multiple components across the application.
```

### Without Global State
```
    App
     └── Parent
            └── Child
                   └── GrandChild

```
- This becomes messy.
- This problem is called: ⚠️ Prop Drilling

### With Global State

Any component can access data directly.
```
    Global Store
        ↑
    Any Component
```

### 🔥 Methods for Global State Management

| Method        | Used For               |
| ------------- | ---------------------- |
| Context API   | Small/medium apps      |
| Redux Toolkit | Large apps             |
| Zustand       | Simple modern apps     |
| Recoil        | React state management |
| MobX          | Reactive state         |


#### ✅ Example of Global State

Data shared across app:

- Logged-in user
- Theme (Dark/Light)
- Shopping cart
- Notifications
- Language
- Authentication token

### Benefits of Global State Management

| Benefit             | Description                |
| ------------------- | -------------------------- |
| Avoid prop drilling | No repeated props          |
| Centralized data    | Easy management            |
| Better scalability  | Good for large apps        |
| Shared access       | Any component can use data |
