# 🟡 What is a Component?

In React:

-  A component is a `small piece of UI` (User Interface)

#### Examples:
```
- Button
- Header
- Card
- Navbar
```
- You build a big app using many `small components`
- Simple Idea
- `Component` = function that `returns UI`

#### 🟢 Example Component
```
function Hello() {
  return <h1>Hello World</h1>;
}

👉 Use it like:

<Hello />
```
## 🧩 Real-Life Example

#### Think like this:
```
🧱 Header component
🧱 Footer component
🧱 Button component
```
👉 Combine them → build a full website

#### 🔁 Reusable Components

👉 Write once, use many times
```
function Button() {
  return <button>Click Me</button>;
}
<Button />
<Button />
<Button />

```
## 🔀 Types of Components
#### 🟢 Functional Component (modern)
```
function App() {
  return <h1>Hello</h1>;
}
```
#### 🔴 Class Component (old)
```
class App extends React.Component {
  render() {
    return <h1>Hello</h1>;
  }
}
```
#### 📦 Component Structure

- Function name starts with capital letter
- Returns JSX
- Can be reused

```
👉 Component = small reusable UI block in React
```
