## Basic concepts: actions, reducers store

### A. Action

***Action*** tells Redux ***what operation we want to perform***.

***Example***:

- Increment counter.
- Decrement counter.
- Add product.
- Remove product.

In `Redux Toolkit`, actions are automatically generated from reducer names inside createSlice().

```
  increment()
  decrement()
```

### B. Reducer
`Reducer` is a function that updates the state.

***counter.slice.js***
```
reducers: {
  increment: (state) => {
    state.value += 1;
  },
  decrement: (state) => {
    state.value -= 1;
  }
}

```

### C. Store
`Store` is the ***central place*** where Redux ***keeps application data***.

- It stores the data.
- React components can access the data.
- It provides a common place to manage shared state.


```
import { configureStore } from "@reduxjs/toolkit";
import counterReducer from './counter.slice.js'

export default const store = configureStore({
    reducer: {
        counter: counterReducer
    }
});


```
