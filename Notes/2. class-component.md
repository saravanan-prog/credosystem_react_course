# 🔴 Class Components (Basic Understanding)

In React:
```
👉 A class component is an older way to create components
👉 It uses a JavaScript class instead of a function
```
#### 🧾 Basic Example
```
import React, { Component } from "react";

class Hello extends Component {
  render() {
    return <h1>Hello World</h1>;
  }
}
👉 Use it like:

<Hello />
```
#### 🧠 How it works (Simple)
```
class Hello       → creates component
extends Component → gets React features
render()          → must return JSX

👉 Whatever is inside render() shows on screen
```
#### 📌 Important Points
- Must use class keyword
- Must have render() method
- Must return JSX inside render()

🟢 Class vs Functional (Easy View)
| Feature  | Class Component | Functional Component |
| -------- | --------------- | -------------------- |
| Syntax   | Complex 😓      | Simple 😊            |
| Used now | Rare            | Mostly used          |
| Hooks    | ❌ No            | ✅ Yes                |


#### ⚠️ Why less used now?
```
👉 Because functional components + hooks are easier and better
```
#### 🎯 Simple Summary

- 👉 Class component = old method using class
- 👉 Uses render() to show UI
- 👉 Now replaced by functional components
