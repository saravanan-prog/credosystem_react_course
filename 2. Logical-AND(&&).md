###  Logical AND (&&)

Used when you want to `render something` only `if condition is true`.

###### Example:
```
function Notification({ hasMessage }) {
  return (
    <div>
      {hasMessage && <p>You have a new message!</p>}
    </div>
  );
}
```
###### Key points:
- No else part
- If condition is false → nothing renders
- Very clean for simple checks
