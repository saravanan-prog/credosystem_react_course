###  Ternary Operator (condition ? A : B)

Used `inside JSX` for `inline conditions`.

###### Example:
```
function Status({ isLoggedIn }) {
  return (
    <h1>
      {isLoggedIn ? "Welcome back!" : "Please login"}
    </h1>
  );
}
```
### Key points:
- `Short` and `concise`
- Must provide both true and false cases
- Can get messy if nested
