## What is Lifecycle?

A React class component goes through 3 major stages:

Figure 1
```

          CLASS COMPONENT
              │
      ┌───────┴────────┐
      ↓                ↓
   MOUNT             UPDATE
      │                │
      │                │
      └───────┬────────┘
              ↓
           UNMOUNT

```
Figure 2

```
              COMPONENT CREATED
                     │
                     ↓
              constructor()
                     │
                     ↓
                  render()
                     │
                     ↓
              componentDidMount()
                     │
                     ↓
              ┌─────────────┐
              │   UPDATE    │
              └─────────────┘
                     │
                setState()
                     │
                     ↓
                  render()
                     │
                     ↓
             componentDidUpdate()
                     │
                     ↓
              ┌─────────────┐
              │   UNMOUNT   │
              └─────────────┘
                     │
                     ↓
          componentWillUnmount()

```

| Method                   | Meaning             |
| ------------------------ | ------------------- |
| `constructor()`          | Initialize          |
| `render()`               | Display UI          |
| `componentDidMount()`    | After first display |
| `componentDidUpdate()`   | After update        |
| `componentWillUnmount()` | Before removal      |
