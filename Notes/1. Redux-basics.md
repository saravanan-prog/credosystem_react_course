## Introduction Redux

**Redux** is a `JavaScript library` used to manage state in an application.
- **Redux stores** application data in ***one central place***.
- Any React ***component can access the shared data***.
- It helps us manage data easily when many components need the same data.

### Simple example:

Imagine an `online shopping application`.

- Product component ***displays products***.
- Cart component ***displays cart items***.
- Navbar ***displays the cart count***.

All `three components` need the ***same cart data***. Redux helps **share this data**.

## Understanding the need for state management
- `State` means ***component data***.
- `State Management` means ***managing application data***.
- `Prop Drilling` means ***passing data through multiple components***.
- `useState` manages ***local state***.
- `Context API` ***shares data between components***.
- `Redux Toolkit` manages ***shared application state***.

### Why do we need Redux
- In React, we normally use **useState** to ***manage data***.
- But when `many components need the same data`, we may ***face a problem called Prop Drilling***.


### Redux Store

**Store** is the ***central place*** where `Redux keeps application data`.


### Redux  Architecture

```
             React Application
                    |
          +---------+---------+
          |         |         |
          v         v         v
        Navbar   Product     Cart
          |         |
          +---------+
                |
                | Dispatch( Action )
                |
                v
              Reducer
                |
                v
            Redux Store
                |
                | useSelector()
                v
          Updated State
                |
                v
           React UI
```

- User performs an ***action***, such as ***clicking a button***.
- React ***component sends an action*** using ***dispatch()***.
- `Reducer` ***updates the state***.
- `Redux Store` ***holds the updated state***.
- React component reads the updated data using ***useSelector()***.
