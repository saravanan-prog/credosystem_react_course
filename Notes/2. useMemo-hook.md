## useMemo() in React

- `useMemo()` is a React Hook used to memoize (cache) 
- expensive calculations to improve performance.
- It prevents `unnecessary recalculations` on `every render`.

### When to Use useMemo()

- Heavy calculations
- Large lists
- Performance optimization
- Filtering/sorting big data


### Syntax
```
    import { useMemo } from "react";

    const memoizedValue = useMemo(() => {
        return expensiveFunction();
    }, [dependencies]);

```




#### Problem Without useMemo()

```

    const squareAreaCalc = (square) => {
        console.log("Running...");
        for(let i=1; i<10000000; i++ ) {}
        return square * square;
    };

    function App() {

        const [count, setCount] = useState(0);
        const [square,setSquare] = useState(5)

        const squareAreaResult = squareAreaCalc(square);

        return (
            <div>
                
                <div>   
                    <label> Enter Sqaure Value </label>
                    <input type="text" 
                        onChange ={(e)=>setSquare(e.target.value)} >
                    <p> Square Area : {squareAreaResult} </p>
                </div>
                
                <div>
                    <p>  Count : {count} </p>
                    <button onClick={() => setCount(count + 1)}>
                    Click
                    </button>
                </div>
               
            </div>
    );
}


```

- Every button click:
```
Component re-renders
       ↓
slowFunction runs AGAIN
```
- even though nothing changed.

# 🔥 useMemo() Solution


```

    const squareAreaCalc = (square) => {
        console.log("Running...");
        for(let i=1; i<10000000; i++ ) {}
        return square * square;
    };

    function App() {

        const [count, setCount] = useState(0);
        const [square,setSquare] = useState(5)

        const squareAreaResult = useMemo(()=> squareAreaCalc(square) , [square] )

        return (
            <div>
                
                <div>   
                    <label> Enter Sqaure Value </label>
                    <input type="text" 
                        onChange ={(e)=>setSquare(e.target.value)} >
                    <p> Square Area : {squareAreaResult} </p>
                </div>
                
                <div>
                    <p>  Count : {count} </p>
                    <button onClick={() => setCount(count + 1)}>
                    Click
                    </button>
                </div>
               
            </div>
    );
}


```
