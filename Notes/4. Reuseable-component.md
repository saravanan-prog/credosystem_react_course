## 🟡 Reusable Components

In React:
```
👉 A reusable component is a component you can
use again and again in different places
```
#### 🧠 Simple Idea
```
👉 Write once → use many times
```
#### 🧾 Example (Without Reuse ❌)
```
<button>Click</button>
<button>Click</button>
<button>Click</button>
```
👉 Repeating code 😓

✅ Using Reusable Component
```
function Button() {
  return <button>Click</button>;
}

👉 Use it many times:

<Button />
<Button />
<Button />

✔ Cleaner
✔ Less code
```
#### 🔁 Reusable with Different Data (Important)


```
👉 Use props to change content

function Button(props) {
  return <button>{props.text}</button>;
}
<Button text="Login" />
<Button text="Signup" />
<Button text="Buy Now" />

👉 Same component, different output 👍

```


#### 🧩 Real-Life Example

Think like:
```
🧱 One “Button” design
Use it everywhere with different text
```
#### 🎯 Why Reusable Components?
- Save time ⏱
- Easy to manage
- Clean code
- Avoid repetition
#### 🧾 One-Line Summary
```
👉 Reusable component = write once, use many times with different data
```
