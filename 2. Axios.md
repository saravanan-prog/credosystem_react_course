## React + Axios (Simple & Practical Guide)

 Axios is a **popular library used in React to make API requests**

 - GET, 
 - POST, 
 - PUT, 
 - DELETE

It is easier than fetch() and provides better 
 - error handling, 
 - interceptors, and 
 - cleaner syntax

#### 1️⃣ Install Axios

```
npm install axios

```

#### 2️⃣ Basic GET Request in React

```

import { useEffect, useState } from "react";
import axios from "axios";

function Users() {
  const [users, setUsers] = useState([]);

  useEffect(() => {
    fetchUsers();
  }, []);

  async function fetchUsers() {
      try {
        const response = await axios.get(
          "https://jsonplaceholder.typicode.com/users"
        );
        setUsers(response.data);
      } catch (error) {
        console.error(error.message);
      }
    }

  return (
    <ul>
      {users.map(user => (
        <li key={user.id}>{user.name}</li>
      ))}
    </ul>
  );
}


```

#### Axios Instance (Best Practice)
axios.instance.js

```
import axios from "axios";

export const api = axios.create({
  baseURL: "https://jsonplaceholder.typicode.com",
  timeout: 5000,
});

```
UserList.jsx
```
import { useEffect, useState } from "react";
import {api} from './axios.instance'

function Users() {
  const [loading,setLoading] = useState(true)
  const [users, setUsers] = useState([]);
  const [error, setError] = useState("");

  useEffect(() => {
    fetchCustomers()
  }, []);

  const fetchCustomers = async() => {
     try{
        const response = api.get("/users")
        setUsers(response.data)
        setLoading(false)
     }
     catch(error){
       setError(error)
     }
  }


  return (


    {!error ?
        <ul>
            {users.map(u => (
                <li key={u.id}>{u.name}</li>
            ))}
        </ul>

    : 
        <button onClick={fetchCustomers}> Re try Fetch user </button>

    }

  );
}
```

#### 6️⃣ Why Axios is better than fetch?

| Feature         | fetch  | Axios     |
| --------------- | ------ | --------- |
| JSON parsing    | manual | automatic |
| Error handling  | tricky | easy      |
| Interceptors    | ❌     | ✅        |
| Timeout support | ❌     | ✅        |
| Cleaner syntax  | ❌     | ✅        |
