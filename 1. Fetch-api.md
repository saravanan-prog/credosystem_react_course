# What is Fetch API?
- Fetch API is a built-in JavaScript tool used to send requests to a server and get data (usually JSON).
- In simple words:
```
    Fetch = “Ask backend for data and get response”
```

#### Basic Syntax

```
fetch(url)
  .then(response => response.json())
  .then(data => console.log(data))
  .catch(error => console.log(error));


```
### GET method handling

```
useEffect(() => {

  const fetchData = async () => {
    try {
      const response = await fetch("https://jsonplaceholder.typicode.com/posts");
      const json = await response.json();
      setData(json);
    } catch (error) {
      console.error(error);
    } finally {
      setLoading(false);
    }
  };

  fetchData();
}, []);
```

###  POST Request Example

```

const sendData = async () => {
  const response = await fetch("https://jsonplaceholder.typicode.com/posts", {
    method: "POST",
    headers: {
      "Content-Type": "application/json",
    },
    body: JSON.stringify({
      title: "New Post",
      body: "This is a post",
    }),
  });

  const result = await response.json();
  console.log(result);
};


```
