### 🔁 React Component Lifecycle (especially for class components)

#### 1. Mounting (component is created and inserted into DOM)

These methods run in order:
```
constructor()       → initialize state
render()            → returns JSX
componentDidMount() → runs after component appears on screen (API calls subscriptions)
```
```
class Example extends React.Component {
  componentDidMount() {
    console.log("Component mounted");
  }

  render() {
    return <h1>Hello</h1>;
  }
}
```
#### 2. Updating (when state or props change)
```
render()
componentDidUpdate(prevProps, prevState)
```
```
componentDidUpdate(prevProps) {
  if (prevProps.value !== this.props.value) {
    console.log("Value changed");
  }
}
```
#### 3. Unmounting (component removed from DOM)
```
componentWillUnmount() → cleanup (timers, subscriptions)
```
```
componentWillUnmount() {
  console.log("Component removed");
}

```
## ⚡ Modern React (Functional Components + Hooks)

- Most developers now use Hooks instead of class lifecycle methods.
- Equivalent using useEffect

```
import { useEffect } from "react";

function Example() {
  useEffect(() => {
    console.log("Mounted");

    return () => {
      console.log("Unmounted");
    };
  }, []);

  return <h1>Hello</h1>;
}
```
### Key patterns:

```
useEffect(() => {}, [])         → runs once (like componentDidMount)
useEffect(() => {}, [value])    → runs when value changes
return () =>   {}               → cleanup (like componentWillUnmount)
```
### 🧠 Simple way to remember
```
Mount       →  component appears
Update      →  data changes
Unmount     →  component disappears
```
