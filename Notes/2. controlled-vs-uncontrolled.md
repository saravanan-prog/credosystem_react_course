
## “controlled” vs “uncontrolled”

In React, “controlled” and “uncontrolled” components refer to how form data is handled.

### Controlled Components

- A controlled component is one where the form data is managed by React state.
- The input’s value is tied directly to state, and updates happen through event handlers.

##### Example:
```
import { useState } from "react";

function ControlledInput() {
  const [value, setValue] = useState("");

  return (
    <input
      value={value}
      onChange={(e) => setValue(e.target.value)}
    />
  );
}
```
##### Key points:
- React controls the input value
- Single source of truth = component state
- Easier validation, debugging, and conditional logic
- More re-renders (can matter in large forms)
## Uncontrolled Components

An uncontrolled component stores its own state internally (in the DOM), and you access it using refs.

Example:

```
import { useRef } from "react";

function UncontrolledInput() {
  const inputRef = useRef();

  const handleSubmit = () => {
    console.log(inputRef.current.value);
  };

  return (
    <>
      <input ref={inputRef} />
      <button onClick={handleSubmit}>Submit</button>
    </>
  );
}
```
##### Key points:
- DOM handles the state, not React
- Use ref to read values
- Less code, simpler for quick forms
- Harder to validate or control behavior
