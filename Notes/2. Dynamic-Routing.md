## Dynamic Routing
Used when you don’t know the exact path in advance (like user profile pages).

##### Step 1: Create dynamic route
```
<Route path="/user/:id" element={<User />} />
```
##### Step 2: Access the parameter
```
import { useParams } from "react-router-dom";
function User() {  
    const { id } = useParams();  
    return <h1>User ID: {id}</h1>;
}
```

##### Step 3: Navigate dynamically
```
<Link to="/user/101">User 101</Link>
<Link to="/user/202">User 202</Link>
```
🧠 Simple mental model
```

/           → Home page
/about      → About page
/user/101   → Dynamic page (id = 101)

```

⚡ Real-world example structure
```
        /              →   Home
        /about         →   About
        /contact       →   Contact
        /user/:id      →   User Profile
```
