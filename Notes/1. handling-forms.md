### Forms in React

- Handling forms in React is mostly about how you capture, store, and validate user input. 

- There are two main approaches: controlled and uncontrolled, plus some best practices.

#### 1. Controlled Form (Most Common)

React manages the form data using state.

##### Example:
```
import { useState } from "react";

function LoginForm() {
  const [form, setForm] = useState({
    email: "",
    password: ""
  });

  const handleChange = (e) => {
    setForm({
      ...form,
      [e.target.name]: e.target.value
    });
  };

  const handleSubmit = (e) => {
    e.preventDefault();
    console.log(form);
  };

  return (
    <form onSubmit={handleSubmit}>
      <input
        name="email"
        value={form.email}
        onChange={handleChange}
        placeholder="Email"
      />
      <input
        name="password"
        value={form.password}
        onChange={handleChange}
        placeholder="Password"
        type="password"
      />
      <button type="submit">Login</button>
    </form>
  );
}

```
#### ✔️ Why use this?
- Easy validation
- Full control over inputs
- Sync UI with data


### 2. Uncontrolled Form

Uses ref instead of state.

##### Example:
```
import { useRef } from "react";

function LoginForm() {
  const emailRef = useRef();
  const passwordRef = useRef();

  const handleSubmit = (e) => {
    e.preventDefault();
    console.log({
      email: emailRef.current.value,
      password: passwordRef.current.value
    });
  };

  return (
    <form onSubmit={handleSubmit}>
      <input ref={emailRef} placeholder="Email" />
      <input ref={passwordRef} type="password" placeholder="Password" />
      <button type="submit">Login</button>
    </form>
  );
}
```
### ✔️ When to use?
- Simple forms
- Less re-rendering
- Quick prototyping
