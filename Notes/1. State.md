# React State

- In React, state is the data that a component stores and manages internally, 
- and it can change over time. 
- When state changes, 
- React automatically updates (re-renders) the UI.

####  What is React State?
```
Think of state as a component’s memory.
```
It holds values like:

- user input
- API data
- counters
- UI toggles (open/close, show/hide)
