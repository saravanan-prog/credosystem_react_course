# 🟡 Component Structure (React)

In React:
```
👉 A component is just a function with a fixed structure
```
#### 🧾 Basic Structure
```
function App() {
  return (
    <div>
      <h1>Hello</h1>
      <p>Welcome</p>
    </div>
  );
}
export default App;
```
## 🧠 Breakdown (Step-by-Step)

#### 1. Function Name -> 👉 Must start with capital letter
```
function App()

```
#### 2. Return JSX
```
return (
  <div>
    <h1>Hello</h1>
  </div>
);
```
👉 This is what shows on screen

#### 3. One Parent Element
```
<div> ... </div>

👉 JSX must have one parent
```
#### 4. Export Component
```
export default App;

👉 So you can use it in other files
```
## 📦 Slightly Bigger Structure
```
import React from "react";

function App() {
  const name = "Ravi";

  return (
    <div>
      <h1>Hello {name}</h1>
    </div>
  );
}

export default App;
```
### 🎯 Simple Structure Formula
```
👉 Component = Function + Return JSX + Export
```
