## “stateful” vs “stateless Components”

In React, “stateful” vs “stateless” components is about whether a component manages its own data (state).

### 🔹 Stateful Components

- A stateful component has its own internal state and can change over time.
- Usually created using hooks like useState (modern React) or class components (older style).

##### Example:
```
import { useState } from "react";

function Counter() {
  const [count, setCount] = useState(0);

  return (
    <>
      <p>{count}</p>
      <button onClick={() => setCount(count + 1)}>Increment</button>
    </>
  );
}
```
##### Key points:
- Maintains state
- Can update UI dynamically
- Handles logic, user interaction
- More powerful, slightly more complex
### 🔹 Stateless Components

- A stateless component (also called a presentational component) does NOT manage its own state.
- It simply receives data via props and renders UI.

##### Example:
```
function Greeting({ name }) {
  return <h1>Hello, {name}!</h1>;
}
```
##### Key points:
- No internal state
- Pure function → same input = same output
- Easier to test and reuse
- Focused only on UI
