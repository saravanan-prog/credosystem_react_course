## Embedding JavaScript in JSX

 In React, you can write JavaScript inside JSX using: **{ }** (curly braces)

### 🧾 Basic Example
```
import {useState} from 'react'

function Demo(){
 

  return (
    <>
      <div>
        <h1>Hello {"Saravanan"}</h1>
      </div>
    </>
  )
}



```

`👉 Output: Hello Arun`
