## Multiple State Handling


- React, you can absolutely use multiple state variables inside a single component. 

- This is very common and often cleaner than putting everything into one object.

#### Basic Idea
```
You just call useState multiple times:
```
```
import React, { useState } from "react";

function Profile() {
  const [name, setName] = useState("Saravanan");
  const [age, setAge] = useState(25);
  const [isOnline, setIsOnline] = useState(true);

  return (
    <div>
      <h1>{name}</h1>
      <p>Age: {age}</p>
      <p>Status: {isOnline ? "Online" : "Offline"}</p>

      <button onClick={() => setAge(age + 1)}>Increase Age</button>
      <button onClick={() => setIsOnline(!isOnline)}>Toggle Status</button>
    </div>
  );
}
```

🔹 Why Use Multiple State Variables?
#### ✅ 1. Better readability
```
 Each state handles one responsibility.
```
#### ✅ 2. Easier updates
```
You don’t need to worry about merging objects.
```
#### ✅ 3. Cleaner logic
```
No unnecessary spreading (...state)
```
# 🔹 Alternative: Single Object State

You can do this:
```
const [user, setUser] = useState({
  name: "Saravanan",
  age: 25,
  isOnline: true
});



setUser({ ...user, age: 26 });

⚠️ But this requires careful updates to avoid losing data.
```
🔹 Pro Tip

- If your component starts having too many state variables, consider:
- grouping them into an object, or
- using useReducer for better structure
