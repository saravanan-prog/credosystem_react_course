## JSX vs HTML

- JSX is used in React
- It looks `like HTML`, but it is `not exactly the same`

## Main Differences :

### 1. class vs className
- 🟥 HTML:&nbsp;&nbsp;&nbsp;  `<div class="box"></div>`
- 🟩 JSX:&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;   `<div className="box"></div>`

👉 Because class is a reserved word in JavaScript

## 2. for vs htmlFor

- 🟥 HTML:&nbsp;&nbsp; `<label for="name">Name</label>`
- 🟩 JSX:&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp; `<label htmlFor="name">Name</label>`

## 3. All tags must be closed

- 🟥 HTML:&nbsp;&nbsp; `<img src="img.png">`
- 🟩 JSX:&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp; `<img src="img.png" />`
## 4. JavaScript inside JSX

- 🟥 HTML: &nbsp;&nbsp;` <h1>5 + 5</h1>`
- 🟩 JSX:&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp; `<h1>{5 + 5}</h1>`
- 👉 Note : `{}` allows JavaScript

## 5. Attribute names are camelCase

- 🟥 HTML: &nbsp;&nbsp; `<button onclick="clickMe()"></button>`
- 🟩 JSX:&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp; `<button onClick={clickMe}></button>`
## 6. One parent element required

#### 🟩 JSX:
```
<div>
  <h1>Hello</h1>
  <p>Hi</p>
</div>
```
