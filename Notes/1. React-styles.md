### 🎨 1. CSS Stylesheets (Traditional CSS)

You write normal .css files and import them.
```
/* styles.css */
.title {
  color: blue;
}
import "./styles.css";

function App() {
  return <h1 className="title">Hello</h1>;
}
```
##### Pros

- Simple and familiar
- Good for global styles

##### Cons

- Class name conflicts (global scope)
- Harder to maintain in large apps
### ⚡ 2. Inline Styles

You write styles directly inside JSX using objects.
```
function App() {
  return <h1 style={{ color: "red", fontSize: "20px" }}>Hello</h1>;
}
```
##### Pros

- Quick and dynamic
- No external file needed

##### Cons

- No pseudo-classes (:hover)
- Not reusable
- Messy for large styling
### 🧩 3. CSS Modules

Scoped CSS (no global conflicts). File naming matters: style.module.css
```
/* style.module.css */
.title {
  color: green;
}
import styles from "./style.module.css";

function App() {
  return <h1 className={styles.title}>Hello</h1>;
}
```
##### Pros

- Locally scoped (no conflicts)
- Clean and maintainable
- Works well for medium/large apps

##### Cons

- Slightly more setup than plain CSS
