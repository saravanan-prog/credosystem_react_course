# Redux
- Redux is a `state management` library
- commonly used with JavaScript apps `especially React`
- to manage and `centralize application state` in a predictable way

### Why React Redux?

Imagine:

- `Navbar` needs `user` info
- `Profile` page needs same `user` info
- `Dashboard` also needs same `user` info




### Without Redux:
- use `props Drilling`
- This becomes messy.

```
Parent → Child → Child → Child props
```

### With Redux:
```
  All components use one central store
```
### Main Things in React Redux

| Thing       | Purpose             |
| ----------- | ------------------- |
| Store       | Stores data         |
| Action      | Tells what happened |
| Reducer     | Updates data        |
| useSelector | Read data           |
| useDispatch | Send action         |
