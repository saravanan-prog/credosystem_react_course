# ⚛️ useState in React

### 🧠 What is useState?
-  State = data that can change inside a component
-  When state changes → UI updates automatically
- useState is a React Hook used to store and update data in a component.

#### 👉 Simple meaning:
```
useState = store value + update value

```
#### 📌 Basic Syntax
```
import { useState } from "react";

const [state, setState] = useState(initialValue);

state           →  current value
setState        →  function to update value
initialValue    →  starting value
```
#### 🔢 Example 1: Counter
```
import { useState } from "react";

function Counter() {
  const [count, setCount] = useState(0);

  return (
    <div>
      <h1>{count}</h1>
      <button onClick={() => setCount(count + 1)}>
        Increase
      </button>
    </div>
  );
}
```
#### 🧠 What happens:
```
- Initial       → count = 0
- Click button  → count = 1, 2, 3...
- UI updates automatically
```
#### 📝 Example 2: Input Field
```
function NameInput() {
  const [name, setName] = useState("");

  return (
    <input
      value={name}
      onChange={(e) => setName(e.target.value)}
    />
  );
}
👉 Whatever you type → stored in state
```


#### ⚡ Important Points
- State changes → UI re-renders
- Always use setState to update
- Never modify state directly

#### ❌ Wrong:
```
count = count + 1;
```
#### ✔ Correct:
```
setCount(count + 1);
```
#### 🎯 Easy Memory Trick
```
useState → remember value
setState → change value
```
#### 🚀 Why it’s important
- Used in almost every React app
- Controls UI behavior
- Essential for forms, buttons, data
