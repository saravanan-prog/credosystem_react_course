## createContext() in React
- createContext() is a` React function` used to create a `Context object for sharing data globally` across components.

- It is part of the `Context API.`


### Flow
```
    createContext()  
       ↓
    Provider - (set the values)
       ↓
    useContext() - (access the context values)
```

### ✅ Syntax

```
import { createContext } from "react";
const MyContext = createContext();

```

### Purpose

- Avoid prop drilling
- Share data globally
- Access data from any component

### Basic Example

##### Step 1 — Create Context

`createContext()` creates a `global context container`.

```
import { createContext } from "react";

export const UserContext = createContext();
```


##### ✅ Step 2 — Provide Data
- `.Provider` is used to share data.
- `value={"Saravanan"}` is the global data.
```
// App.js

import { UserContext } from "./UserContext";
import Home from "./Home";

export default function App() {
    return (
        <UserContext.Provider value={"Saravanan"}>
            <Home />
        </UserContext.Provider>
    );
}

 
```

##### ✅ Step 3 — Use Data


`Home.js`

```
import { useContext } from "react";
import { UserContext } from "./UserContext";

function Home() {
    
    const user = useContext(UserContext);
    return <h1>{user}</h1>;
}

export default Home;
```
