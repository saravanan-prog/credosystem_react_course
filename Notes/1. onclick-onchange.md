### onClick

onClick is triggered when a user clicks on an element (like a button, div, etc.).

Example:
```
function ClickExample() {
  const handleClick = () => {
    console.log("Button clicked!");
  };

  return <button onClick={handleClick}>Click Me</button>;
}
```
#### Key points:
- Used for mouse clicks
- Common with buttons, links, icons
- Triggers once per click
### onChange

- onChange is triggered when the value of an input changes.
- Mostly used with form elements like input, textarea, select.

#### Example:
```
import { useState } from "react";

function InputExample() {
  const [text, setText] = useState("");

  return (
        <>
            <div>
                <input type="text" onChange={(e)=>setText(e.target.value)} />
            </div>
            <div className="mt-3">
                <span className="h3">Typed Text : </span>
                <span>{text}</span>
            </div>
        
        
        </>
    )
}
```
#### Key points:
- Used for form inputs
- Fires on every keystroke (for text inputs)
- Essential for controlled components
