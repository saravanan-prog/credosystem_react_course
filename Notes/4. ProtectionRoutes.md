### Protection routing

- “Protection routing” in React usually means restricting access to certain routes/pages based on authentication or roles. 

- The most common way to do this today is with React Router (v6+).
Let’s walk through the clean, modern approach.

### 🔐 1. Basic Idea

- You create a Protected Route wrapper that:
- Checks if the user is logged in
- If yes → allow access
- If not → redirect to login page



### ⚙️ 2. Example Setup (React Router v6)
#### Install
```
npm install react-router-dom
```


#### Protected Route Component

#### ProtectedRoute.jsx
```
import { Navigate } from "react-router-dom";


export default const ProtectedRoute = ({ children }) => { 

    const token = localStorage.getItem("token") ? true : false; 

    if (!token) {    
        return <Navigate to="/login" replace />;
    }  
    return children;
};
```
### Use It in Routes

```
import { BrowserRouter, Routes, Route } from "react-router-dom";
import ProtectedRoute from "./ProtectedRoute";
import Dashboard from "./Dashboard";
import Login from "./Login";

export default function App() {
  return (
    <BrowserRouter>
      <Routes>
        <Route path="/login" element={<Login />} />

        <Route
          path="/dashboard"
          element={
            <ProtectedRoute>
              <Dashboard />
            </ProtectedRoute>
          }
        />
      </Routes>
    </BrowserRouter>
  );
}

 
```

### 🧠 3. Role-Based Protection (Advanced)
You can extend it for roles (admin/user):
```
export default const ProtectedRoute = ({ children, role }) => {
  const user = JSON.parse(localStorage.getItem("user"));

  if (!user) return <Navigate to="/login" />;

  if (role && user.role !== role) {
    return <Navigate to="/unauthorized" />;
  }

  return children;
};
```
Usage:
```
<Route
  path="/admin"
  element={
    <ProtectedRoute role="admin">
      <AdminPage />
    </ProtectedRoute>
  }
/>
```

### 🚀 4. Best Practices


- Use JWT tokens stored securely (prefer httpOnly cookies over localStorage in production)
- Keep auth state in Context API or Redux
- Show loading state while checking auth
- Handle token expiry (auto logout)



### ⚡ 5. Alternative Pattern (Layout-based)

// auth.js
export const isAuthenticated = () => {
  return !!localStorage.getItem("token");
};



### Instead of wrapping each route:
```
<Route element={<ProtectedRoute />}>
  <Route path="/dashboard" element={<Dashboard />} />
  <Route path="/profile" element={<Profile />} />
</Route>
```
### And inside ProtectedRoute:
ProtectedRoute.js
```
import { Outlet } from "react-router-dom";
import { isAuthenticated } from "./auth";



return isAuthenticated() ? <Outlet /> : <Navigate to="/login" />;
```
