## 1. Yup

  Yup is a JavaScript library used for validating data—especially form inputs in apps built with React.

 ```
 Yup = validation rules + error handling
 ```


 ## 2. Why We Use Yup

 ##### Without Yup:

- You manually write lots of if conditions
- Code becomes messy

##### With Yup:

- You define validation once
- It automatically checks everything


Step 1: Install Yup
```
 npm install yup
```


### 3. Basic Schema Structure

```


import * as Yup from "yup";

const schema = Yup.object({
  name: Yup.string().required(),
});

```


### 🔹 2. String Validations
```
name: Yup.string()
  .required("Required")
  .min(3, "Too short")
  .max(20, "Too long")
  .matches(/^[A-Za-z]+$/, "Only letters")


👉 Common:

required()
min(), 
max()
matches() 
(regex)
```


### 🔹 3. Email Validation
```
email: Yup.string()
  .email("Invalid email")
  .required("Email required")
```

### 🔹 4. Password Validation (Strong)
```
password: Yup.string()
  .required("Password required")
  .min(6, "Min 6 chars")
  .matches(/[A-Z]/, "One uppercase required")
  .matches(/[0-9]/, "One number required")
  .matches(/[!@#$%^&*]/, "One special char required")
```

### 🔹 5. Number Validation
```
age: Yup.number()
  .required("Required")
  .min(18, "Must be 18+")
  .max(60, "Too old")
  .positive()
  .integer()
```
### 6. Boolean Validation
```
terms: Yup.boolean()
  .oneOf([true], "Accept terms")
```
###  7. Date Validation
```
dob: Yup.date()
  .required("Required")
  .max(new Date(), "Future date not allowed")
```
### 8. Confirm Password
```
confirmPassword: Yup.string()
  .oneOf([Yup.ref("password")], "Passwords must match")
  .required("Required")
```

### 9. Nested Object Validation
```
address: Yup.object({
  city: Yup.string().required(),
  zip: Yup.string().required(),
})
```
### 10. Array Validation
```
skills: Yup.array()
  .min(1, "Select at least one skill")
```
### 11. Conditional Validation
```
phone: Yup.string().when("contactMethod", {
  is: "phone",
  then: (schema) => schema.required("Phone required"),
})
```

### 12. Custom Validation
```
username: Yup.string().test(
  "no-admin",
  "Admin not allowed",
  (value) => value !== "admin"
)
```

### 13. Transform / Trim
```
name: Yup.string()
  .trim()
  .required("Required")

```

### 14. Full Real-World Schema

```
const validationSchema = Yup.object({
  name: Yup.string().min(3).required(),

  email: Yup.string()
    .email()
    .required(),

  password: Yup.string()
    .min(6)
    .matches(/[A-Z]/)
    .matches(/[0-9]/)
    .required(),

  confirmPassword: Yup.string()
    .oneOf([Yup.ref("password")])
    .required(),

  age: Yup.number()
    .min(18)
    .required(),

  terms: Yup.boolean()
    .oneOf([true]),

  skills: Yup.array()
    .min(1),
});

```
